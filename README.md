# Town_Propverse - 3D Real Estate Town

Live Demo: https://town-propverse.vercel.app

A 3D real estate visualization platform for Pakistan. It shows a full town layout with 60 plots, roads, and amenities in real-time 3D.

**What it does:**
- Interactive 3D town (300x300m) with 60 plots - 5, 7, 12 Marla
- Roads, boulevard, markets, masjids, hospital, boundary wall
- High performance - <2.5s load, low draw calls

**Built with:**
Next.js, TypeScript, Three.js, React Three Fiber, Supabase, Docker

**How to run:**
npm install
npm run dev
